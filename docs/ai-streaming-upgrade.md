## 实现内容

1. 供应商适配器发送 `stream: true`，解析 SSE 内容增量、分段工具参数、结束原因及 usage。仍兼容供应商返回完整 JSON 的情况，此时不会伪造逐字动画。忽略 reasoning 字段，仅显示公开回复。
2. 新增只读 `GET /api/v1/runs/{run_id}/events`。后台在收到增量时把草稿保存到既有 ModelAttempt JSON 字段，SSE 约每 150ms 检查变化并发送快照；断线重连、刷新与历史回看都不触发新模型调用。无数据库迁移。
3. 提交后留在智能分析页，按顺序显示用户问题、助手回复、工具调用、核验后的数值与报告入口。补充条件、停止执行、失败后重跑、继续追问均可操作。追问通过可选 `conversation_parent_run_id` 新建关联任务，沿用原对话数据集；上下文最多携带前八轮，历史任务仍完整保存。
4. 输入支持 Enter 发送、Shift+Enter 换行，中文输入法确认键不误发送。阅读旧消息时不强制滚到底部，可返回最新消息。执行中允许起草下一条，禁止并发提交。
5. 草稿、未完成输出、未通过核验版本和最终结果有不同提示。取消保留已收到的内容；上游长时间没有新片段时，取消可能需要等到下一片段或既有超时边界，不虚称立即撤销供应商已发生的用量。
6. 配置继续从原有环境变量 / `.env` 服务端读取。密钥未进入前端，未改 `.env`、模型 ID、额度、数据库结构、依赖或锁文件。授权门槛、白名单工具、精确金额、幂等提交与报告核验保留。
