1. **源码与归档**：初始工作区为空，无 Git。将 ZIP 原样解压为子目录 ecommerce-agent-thesis，原位开发；按用户全局约定把额外交付与任务缓存放 D 盘。该用户约定优先于 D0 文档“只修改工作区”的一般描述；源码未被迁移。审批服务 503 重试成功才创建 D 盘目录。
2. **阶段范围**：只建立 `app_metadata` 和 Alembic 版本表，不提前创建 D2 交易表、不下载 D1 文件。健康成功仅表示 D0 工程可用。业务、模型、论文和正式实验均保持未开始。
3. **健康语义**：迁移显式执行；GET 使用 SQLite `mode=ro`，核对实际表/项目标记/当前 revision，缺库或不就绪返回 503，不隐式创建、升级数据库或假返回成功。
4. **本地配置**：Pydantic 从根 .env 读取；相对数据库路径固定相对项目根。模板遵守本次 D 盘目录约定。只允许本机监听，精确 Host/Origin，统一脱敏异常；不提前声称未开发上传、导出等安全面通过。
5. **依赖与管理**：Python .venv 与 npm node_modules 作为项目依赖留在源位置；锁定实际安装的完整图与直接版本。manage 自动使用 .venv，所有测试/构建失败保留退出码；未来阶段命令返回 NOT_IMPLEMENTED。
6. **缓存与证据**：pytest 每次独立目录、Vite 使用 runner 配置加载避免配置临时文件落源码目录；Playwright 包装器在加载配置前设置浏览器/转译缓存。D 盘保留失败日志、每次命令 argv、时间、退出码、数据库/包哈希和截图/trace。已存在共享依赖与全局缓存不搬迁。
7. **真实浏览器**：使用本机 Edge，工程隔离数据库、随机端口，调用实际 manage 启动命令。停止/恢复测试终止自己创建的进程树，标记 intentional_stop，结束后清理。默认 8000/5173 再通过真实启动/代理/API/SQLite完整性验证。
8. **遗留告警**：npm 在现有版本范围修复后仍有 4 个间接开发依赖 moderate 告警，生产依赖 audit=0。保留而非用未经验证的主版本 override 消除输出；Starlette/httpx 弃用提示同样如实记录。
9. **版本与交接**：原始 PACKAGE_MANIFEST.json/不可变资料保持不变，开发状态只更新 STATUS 等允许变更文件。没有自动创建 Git commit；SHA=null，通过源码文件清单与 ZIP SHA256 定位本次交付。用户验收 D0 后才可进入 D1。
