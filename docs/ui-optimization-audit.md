## 跨页面问题

- P1：辅助文字 #94A3B8 在白色背景对比度不足，字号最低 11px。提升正文 14px、辅助 12–13px，深色语义文字与可见焦点。
- P1：未保存问题在刷新时丢失；基期日期可只填一项；切换快速请求可能覆盖新页面。增加离开提示、成对校验与请求代数检查，保持 API 契约。
- P2：状态标签默认绿色；失败/等待标签未绑定状态。按实际枚举统一颜色和文字，禁止凭颜色表达。
- P2：表格可横向内部滚动，但键盘无明确可聚焦入口。增加区域语义、tabindex、窄屏限制。
- 未发现需阻止实施的 P0。无流程编辑器、登录/授权管理、新增商品/编辑商品页面，均不制造不存在的页面。
