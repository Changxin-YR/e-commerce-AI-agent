# 本地操作、演示与恢复手册

## 启动与数据

在README指定根目录执行doctor，然后分别启动backend与frontend。首次安装先安装锁定依赖、配置.env并显式migrate。API0.9.0/D9，schema0004_agent_runtime；健康成功不等于模型验收。

“数据与导入”选官方ZIP/XLSX并上传。页面轮询QUEUED/IMPORTING，READY后才能分析。541909原行全保留，530104正向、9288取消、2517其他、0无效。135080缺客户号、1454缺描述、5268重复候选是已知质量，不自动删行。首次导入约数分钟，实际耗时见日志；再传同ZIP/XLSX应复用。

损坏/超大/路径穿越/宏/外链/未审计工作簿被拒绝，错误不回显本地路径。中断后的失败批次可重新提交官方源，完整处理后才发布READY。不要在导入中手工改库。

## 无模型演示（约5—10分钟）

1. 查看来源/哈希/质量，重复上传官方XLSX确认复用。
2. 经营概览选2011-09：正向1058590.172、取消38902.550、净额1019687.622、发票1837；2011-10：1154979.300、84274.630、1070704.670、2040。这些是开发对账值，API仍实际计算数据库。
3. 保存查询，进入查询历史打开并刷新，只读保存结果。
4. 智能分析显示B1/B2 BLOCKED_AUTHORIZATION。用确定性报表表单选2011-10-01至2011-11-01（结束不含）；可选基期2011-09-01至2011-10-01，生成B0报告。
5. 报告详情核对差额51017.048、引用、版本/过滤器/限制，下载JSON/Markdown；查看来源任务显示B0无模型用量。
6. 2011-12为PARTIAL_PERIOD；2012年为NO_DATA；覆盖期内无匹配是EMPTY_RESULT；基期不足可能PARTIAL_RESULT。不把无数据当零收入。
7. Ctrl+C停后端，确认页面错误；重新启动并刷新同一报告链接，内容保留。最后停止两个服务。

任务与实验页面仅显示开发任务/历史用量。默认库内test_fixture_no_network的B1/B2记录只证明工程恢复机制，没有正式实验成绩或真实模型结论。

## 追问与异常

B1为多轮工具循环，B2额外检查显式条件、金额/引用及有限修复。实际模型需授权后验证。ScriptedProvider通过专用测试工厂注入，普通.env/API不能开启；日常后端不要使用测试工厂。

WAITING_INPUT保存thread/checkpoint。重启后进入同一任务，补全所有字段并提交；重复补答复用键，不生成双份报告。RUNNING进程中断后为INTERRUPTED；已发送未确认尝试记UNKNOWN_OUTCOME，确认token未知，保守额度占用保留。明确恢复才继续；代码/预算变化导致RUN_CONFIG_CHANGED时用重新运行，创建新run/thread并保留parent_run_id。

取消在安全边界生效，不保证撤回已发送调用。额度耗尽、未知错误、核验失败都显示实际错误，不伪装为无数据。GET历史不重放图、不调用provider。

## 配置与备份

.env不提交/截图/外发。APP_HOST仅localhost/127.0.0.1，默认8000/5173，改端口后重启两服务。DATABASE_URL为本地SQLite，D0_CACHE_DIR为当前任务构建/测试缓存，IMPORT_CACHE_DIR为上传缓存。上传50MiB写在代码中，旧UPLOAD_MAX_BYTES占位已移除。MODEL_MAX_TOTAL_COST没有实现，不能当费用上限。

备份前停止两服务和验证脚本。app.sqlite3与app.checkpoints.sqlite3必须成对保存；若仍有WAL/SHM，先用SQLite备份API或干净关闭后复制，不遗漏尚未合并的WAL。本轮交付在停止服务后记录SHA并配对保存。恢复到新任务目录，修改.env路径，不覆盖封存原件。

清理任务缓存可能删除当前运行库，应先保留交付备份。源码ZIP不带原文件、数据库、.env、依赖；复现需取得官方源/核对哈希并安装锁定依赖。此版没有多用户认证，不自动暴露公网。

每轮浏览器证据在缓存/playwright/时间目录，命令记录保留argv、UTC起止、退出码和原始输出；失败另存、复测新目录。用户最终验收必须亲自完成以上操作并确认；Codex只提交READY_FOR_USER_ACCEPTANCE并保留模型阻断。
