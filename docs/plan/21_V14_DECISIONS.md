## B. 最小必做与可延期项（**不等于无授权缩小最终研究目标**）

- **E-S1 入口**：后端初始化 + UCI真实文件核查 + 行分类精确计算 + 幂等导入 + FastAPI月度查询 + Vue一个真实交互页 + E01—E10。
- **E-S2 Agent入口**：同模型/同工具的 B1 和 B2；至少 5 个有效工具（profile、metric_definitions、query_metric_series、rank_entities、compare_periods），能够处理明确查询、缺参追问、无字段拒绝和工具错误；一次真实保存/恢复。运行预算通过冒烟校验。
- **E3 全功能**：在 E-S2 验证可靠后补齐 8 工具与剩余 4 功能视图（允许合并为三个页面路由）。形式可精简，能力和证据不可删除。若希望放弃某一能力，必须经用户重新确认并在论文选题/任务集中同步收缩，不能测试失败后删测试题。
- **E4/E5 实验**：B1 不能删。默认 30 条 dev + 90 条主 test + 10 故障 test；有资源压力可以在**正式 test 冻结前**与用户明确商定更小的研究规模，提前变更协议并解释统计限制，禁止因为测试成绩不理想而临时调小样本。
- **E6 论文**：如实讲述方法、失败与成本；不声称提高准确率直到完成实际对照。

## C. 模型提供方接入的最低验收与估算

- **实际配置**：`MODEL_PROVIDER`、`MODEL_ID`、`MODEL_BASE_URL`、真实 `MODEL_API_KEY`（仅本地环境）；`ALLOW_PAID_MODEL_CALLS=false` 默认；正数批次请求/token 限额需用户明确确认。没有 Key 不算 P0，模型和正式效果处于 BLOCKED。
- **真实冒烟**：真实 provider 执行 5 个开发任务：单月问数、比较、缺月份、利润不可支持、工具错误；记录原始 `tool_calls`、结束原因、token 用量、重试和响应时间。失败则记录支持矩阵，尝试适配，不隐瞒。
- **估价**：先观察平均尝试数、输入输出 tokens、当前可核实的模型官方费率，再估算 `90 × 2 × 3` 条主评估以及 `10 × 2 × 3` 条故障评估。没有费率证据则只报告数量和 token，不引用 Claude 所给每次 `$0.05-$0.15` 估价作为事实。
- **公平性**：两组同一提供方、模型、参数、公共工具、结构、基础错误处理、限额；B2额外流程步骤与成本同时核算。SDK/框架自动重试由 provider 适配层统一记录。

## D. 最简可靠运行契约

- 一次最多运行一个本地任务；SQLite 记任务和输入，图保存在 SQLite checkpointer；`run_id/thread_id` 固定、状态持久。
- 只有读历史 `GET` 不触发任何模型；正在等待回复的 run 可重启后继续，用同一 thread 和 `Command(resume=...)`。
- 在 `interrupt()` 所在节点的恢复会重新运行节点前部代码，所有写入必须幂等；不复写已有的 finalized report；重复点击只返回现有任务或冲突码。
- 终止运行/未知调用结果按照 `10_RUNTIME_CONTRACT.md` 如实记录；实现可简单，但不能抹去发生或可能发生的模型调用。禁止默认从零开始重试并宣称完全恢复。

## E. 安全范围与测试等级

- S04（ZIP路径/解压/格式与资源）、S05（导出公式）、S06（参数/注入）、S07（无授权模型调用）、S08（幂等）、S09（历史只读）、S12（Host/Origin/CSRF）是电商场景必须验证的类别；不适用项明确 N/A。S10 要检查日志和页面的密钥泄漏。
- **不做**任意 URL 拉取能力；官方 UCI 的硬编码来源下载不等于用户可控 SSRF。若后续增加 URL 上传，必须重新启用 S01/S02 相关测试和访问限制。
- 请以 2—3 条自动化浏览器流程检查：真实导入+概览、月度精确查询与刷新、自然语言缺参补答与历史只读。后者必须模型授权后跑实际端到端；没有条件时保留阻断状态。

## F. 对 Codex 的交付规则

每轮只做一个可核验切片，优先逐步实现/运行，不要一口气把所有空文件堆满。不可用配置或资源列为具体阻碍并继续独立步骤。始终记录 Git diff/commit、测试退出码、截图路径、数据校验和未完成状态。项目无其他历史代码时，Codex 自己创建 pyproject、FastAPI main、Vue package、Alembic；不需要用户提前手建空骨架。

详见 `CODEX_BRIEF.md`，所有旧 V1.1/V1.2 文档只按其适用范围读取；本文件与下层规范矛盾时在 DECISIONS 留痕。所有实测结果仅在用户实际环境执行后记 PASS。
