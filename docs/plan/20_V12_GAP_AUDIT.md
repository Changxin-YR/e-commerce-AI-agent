## 仍然存在且不能由文字“消除”的真实外部依赖

1. 学院具体论文格式、导师确认要求；现在不能代替学院批准。
2. 用户机器的 Codex 环境、Python/Node、网络与现有代码；当前不等于已经启动用户的 Windows 系统。
3. 获客的真实官网访问率、是否可取得足够有代表性的企业及真实人工金标准。
4. 真实模型 API 的合法凭据、供应商兼容性与实际使用额度。
5. 用户本人或实际标注者对研究参考答案和企业标签的复核。

**最终判断：开发交接 `HANDOFF_READY`；工程实际 `IMPLEMENTATION_NOT_STARTED`；研究正式 `EVALUATION_NOT_STARTED`。** 后两项的完成只能靠真实开发证据与人工审核，不能由本计划包给出 PASS。
