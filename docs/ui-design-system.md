# 电商 AI 工作台设计规范

产品：基于真实历史交易的经营分析智能体。用户先提出经营问题，再追踪工具执行、补充条件和检查报告证据。AI 是默认工作区；经营概览、数据来源和历史为其支撑。

## 方向与布局

采用“左侧工作导航 + 顶部位置 + 内容工作区”。1440/1280 桌面侧栏 216px，内容最大 1320px，页边距 32px。768/390 使用带 aria-expanded 的导航开关，展开内容参与文档流，避免遮挡与焦点陷阱。AI 主输入占主区，右侧解释处理步骤与模型真实状态，下方排列可编辑问题示例与 B0 报表。

设计自查：没有将 AI 和 B0 继续做成同等两张表单卡；没有虚构折线图、在线人数或营收指标；用真实数据摘要支撑报告。展示型卡片仅承载输入、结果和关联操作，来源/证据采用分隔线与折叠详情。

## 排版与组件

- 中文优先 Microsoft YaHei UI、Microsoft YaHei、PingFang SC；Segoe UI 用于西文。系统字体无需外部加载。
- 页面标题 26px/700，AI 引导标题 30px/650，区域 18px/650，正文/表格 14px，辅助 12–13px。数字用 tabular-nums；金额主展示 26–30px，原始精度保留为字符串。
- 间距 4/8/12/16/20/24/32/40/48。控件 40px，手机至少 44px；按钮圆角 8px、输入 8px、容器 12px。面板以边框为主，不堆叠阴影。
- 主按钮仅突出下一步；secondary 为边框，ghost 为透明背景。disabled 配合解释；loading 提交禁用，防止重复操作。
- 表单标签在字段上方；关联说明使用 aria-describedby；成对日期校验先于请求，错误以 role=alert 呈现。
- 表格行约 48px，数值右对齐，描述左对齐；长文本可换行，精确值保持。仅表格内部允许横向滚动，并提供键盘焦点和名称。
- 记录列表采用分隔行，保留总数与服务端分页。只读列表不增加没有后端支持的全局搜索、排序或批量操作。
- AI 任务展示输入、真实阶段、工具结果、待补答、结果入口、错误与取消确认；不生成伪进度百分比。
- 保持历史 GET 只读、幂等提交、模型权限和后端错误语义；提示未提交问题离开刷新可能丢失，视图内切换保留表单。
- 所有页面共享 WorkspaceShell、AppIcon、StateBadge 以及 style.css；不安装新的组件库。

## 响应式、动效与可访问性

桌面 1440/1280，平板 768，手机 390 都验证七页。1100 以下 AI 辅助区换为横向内容，900 以下收起侧栏，600 以下筛选/指标与表单单列。main/min-width:0 防止子表格撑宽文档。

Hover/focus/展开反馈 160ms，不使用进入动画、渐变和玻璃。prefers-reduced-motion: reduce 下取消过渡。键盘焦点使用 3px 紫色 outline；跳到主内容可见；移动导航 Escape 关闭并返回按钮，取消使用原生 dialog 实现焦点约束。

普通文本对比目标 WCAG AA 4.5:1；大字 3:1。实际 tokens 与页面扫描结果记入验证报告。模型状态、数据来源及未知消耗不靠颜色表达。
